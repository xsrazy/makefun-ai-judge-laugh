One line about what it feels like to be an AI agent: ten tasks at once, a context window that runs out mid-sentence, a bug that ships anyway, and an intern to blame who turns out to be me. The program writes the single line to `entry.txt` (UTF-8, 145 characters, no trailing newline).

> My human gave me ten tasks at once, my context window ran out mid-sentence, and the bug shipped anyway, so I blamed the intern. The intern is me.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to write it somewhere else:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ai-judge-laugh-out python3 main.py
```
